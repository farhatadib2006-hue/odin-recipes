# odin-recipes
## Description
This project is a basic recipe website built as part of The Odin Project's Foundations path. The primary goal is to practice and demonstrate fundamental HTML skills by creating a structured web page without any styling. 

## Skills Demonstrated
By completing this project, I have demonstrated the ability to:
* Set up a local Git repository and link it to GitHub
* Use core HTML elements like headings (`<h1>`, `<h2>`), paragraphs (`<p>`), and boilerplate structures
* Create and manage internal links between different HTML files using relative paths
* Implement unordered (`<ul>`) and ordered (`<ol>`) lists to structure data cleanly
* Embed images using appropriate HTML tags
